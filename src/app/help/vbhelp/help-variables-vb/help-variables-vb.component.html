Variables (Visual Basic Style)

Variables allow you to store values and use them throughout your program.

Integer Variables

You can declare and use integer variables to store numeric values:
  • Declare a variable with: Dim variableName As Integer = value
  • Use the variable in method calls and expressions

Example

Sub main()
  Dim distance As Integer = 3
  Dim runner As Jeroo = New Jeroo()
  runner.hop(distance)
End Sub

In this example:
  • distance is an integer variable set to 3
  • The Jeroo will hop 3 times using the value stored in distance
